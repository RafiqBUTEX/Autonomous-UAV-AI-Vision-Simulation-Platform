# Autonomous UAV AI Vision Simulation Platform

An end-to-end autonomous aerial robotics research platform built using **PX4 SITL**, **ROS 2**, **Gazebo Classic**, and **MAVROS**.

## Project Goal

Develop an autonomous UAV capable of:

- Autonomous offboard flight
- Waypoint navigation
- Obstacle detection and avoidance
- SLAM-based mapping
- Computer vision
- Reinforcement learning
- Unity3D digital twin
- Applications in precision agriculture, environmental monitoring, and search & rescue
